Airport LoungesVisa · RuPay

Airport lounges: Visa and RuPay integrations

Pine Labs · Associate Product Manager

Brought lounge access onto the Visa and RuPay networks and automated entitlement setup through APIs.

+30%lounge value from Visa
87lounges on RuPay BMS
−25%operational effort
›How I built it
ProblemEntitlements were configured by hand. Frequent bank and network rule changes meant wrong entitlements reached cardholders, and onboarding new banks and BINs was slow.
What I didLaunched the Visa offer engine across Pine Labs lounges, the first network live. Then rolled out RuPay's Benefit Management System and moved entitlement configuration to APIs.
ResultVisa added 6K daily transactions and 30% lounge transaction value. RuPay added 4.5K daily transactions across 200+ BINs and 87 lounges. Operational effort fell 25%.
PetroleumFuel & DEF retail

Fuel & DEF retail: activation and TATA DEF payments

Pine Labs · Product Manager 1

Fixed the activation bottleneck for fuel outlets, and launched CRM-integrated payments for TATA's DEF stations.

4 → 1activation steps
+15%merchant activation
₹35L/moacross 400+ DEF stations
›How I built it
ProblemTransaction data showed flat activation. Merchant interviews found the cause: a two-app journey that re-asked outlet owners for details they'd already given at onboarding.
What I didCollapsed activation into one step. For TATA, built DEF payments around the CRM integration they needed, posting the vehicle number at fueling instead of an offline flow, and cut inventory management as low-impact.
ResultMerchant activation up 15%. DEF payments run at ₹35L a month across 400+ stations. I also migrated a fuel retailer off an incumbent POS vendor in a month.
